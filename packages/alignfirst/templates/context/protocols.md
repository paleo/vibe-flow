# AlignFirst Protocols

`{{CMD}} guide <protocol>` prints a collaborative protocol to follow when the user names AlignFirst or a protocol alias. A guide already in context is not reloaded. Each named guide includes the ticket directory and work file rules; `--protocol-only` omits them when they are already in context.

Aliases: `alspec` → `spec`, `alplan` → `plan`, `al` or `AAD` → `aad`, `almerge` → `merge`, `alreview` → `review`, `aldescription` → `description`. `alcatchup` stands for `{{CMD}} ticket --catchup` followed by the user's instructions; `alcatchupaad` and `alcatchupspec` run it before the `aad` or `spec` protocol.
